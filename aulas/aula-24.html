Validando Atributos

O que são atributos HTML?

Atributos são informações adicionadas aos elementos HTML para definir características ou comportamentos.

Por exemplo: 

<input
type="email"
id="email"
name="email"
placeholder="Digite seu e-mail"

>

Nesse exemplo, temos diversos atributos:

type → define o tipo do input.

id → identifica o elemento.

name → identifica o campo em um formulário.

placeholder → apresenta uma mensagem de orientação.

1. Validando a existência de um atributo

Para verificar se um elemento possui determinado atributo, podemos utilizar a asserção have.attr.

Imagine o seguinte elemento: 

<input
type="email"
id="email"

>

Podemos verificar se o elemento possui o atributo type: 

cy.get('#email')
.should('have.attr', 'type')

have.attr → verifica a existência de um atributo.

type → nome do atributo que queremos validar.

2. Validando o valor de um atributo

Também podemos verificar não apenas se o atributo existe, mas qual é o seu valor.

Considere: 

<input
id="email"
type="email"

>

Podemos validar o valor do atributo type: 

cy.get('#email')
.should('have.attr', 'type', 'email')

Nesse caso, o teste verifica duas informações:

1️⃣

Atributo

O elemento precisa possuir o atributo type.

2️⃣

Valor

O valor do atributo precisa ser email.

3. Validando diferentes atributos

A mesma estratégia pode ser utilizada para diferentes atributos HTML. 

<input
id="email"
type="email"
name="email"
placeholder="Digite seu e-mail"

>

Podemos validar o atributo type: 

cy.get('#email')
.should('have.attr', 'type', 'email')

Validar o atributo name: 

cy.get('#email')
.should('have.attr', 'name', 'email')

E também o placeholder: 

cy.get('#email')
.should(
    'have.attr',
    'placeholder',
    'Digite seu e-mail'
)

4. Validando data attributes

É muito comum aplicações utilizarem atributos personalizados iniciados por data-.

Por exemplo: 

<button
data-testid="login-button"

>
Entrar

Podemos verificar esse atributo utilizando have.attr: 

cy.get('[data-testid="login-button"]')
.should(
    'have.attr',
    'data-testid',
    'login-button'
)
Boa prática:

Atributos dedicados à automação podem ajudar a criar seletores mais estáveis quando utilizados de forma consistente no projeto.

5. Validando classes CSS

Classes também podem ser importantes para verificar o estado ou a aparência de determinados elementos.

Considere: 

<button class="btn btn-primary">
Entrar

Podemos verificar se o elemento possui a classe btn-primary: 

cy.get('button')
.should('have.class', 'btn-primary')

have.class → verifica se um elemento possui determinada classe CSS.

6. Validando elementos com várias classes

Um elemento pode possuir várias classes ao mesmo tempo. 

<button class="btn btn-primary active">
Entrar

Podemos validar cada classe individualmente: 

cy.get('button')
.should('have.class', 'btn')
.and('have.class', 'btn-primary')
.and('have.class', 'active')

Dessa maneira, conseguimos verificar diferentes características do mesmo elemento.

7. Validando o valor de um input

Inputs possuem uma característica importante: o valor atual preenchido pelo usuário.

Podemos utilizar a asserção have.value. 

<input
id="email"
type="email"
value="usuario@email.com"

>

O teste pode verificar esse valor: 

cy.get('#email')
.should('have.value', 'usuario@email.com')

have.value → verifica o valor atual de um elemento de formulário.

8. Validando o tipo de um input

Uma validação bastante comum é verificar se um campo possui o tipo esperado. 

<input
id="senha"
type="password"

>

Podemos validar o atributo: 

cy.get('#senha')
.should('have.attr', 'type', 'password')

Dessa forma, conseguimos garantir que o campo foi configurado como um campo de senha.

9. Validando links

Links normalmente possuem o atributo href, que indica o endereço de destino. 

<a
href="/produtos"

>
Produtos

Podemos validar o destino: 

cy.get('a')
.should('have.attr', 'href', '/produtos')

Essa validação pode ajudar a verificar se links importantes da aplicação estão configurados corretamente.

10. Validando outros atributos de links

Também podemos validar atributos adicionais presentes em links. 

<a
href="https://exemplo.com"
target="_blank"

>
Acessar

Podemos verificar o atributo target: 

cy.get('a')
.should('have.attr', 'target', '_blank')

Também podemos verificar o href: 

cy.get('a')
.should(
    'have.attr',
    'href',
    'https://exemplo.com'
)

11. Utilizando múltiplas validações

Podemos realizar várias asserções sobre o mesmo elemento. 

<input
id="email"
class="form-control"
type="email"
name="email"
placeholder="Digite seu e-mail"

>

O teste pode validar diferentes características: 

cy.get('#email')
.should('have.class', 'form-control')
.and('have.attr', 'type', 'email')
.and('have.attr', 'name', 'email')
.and(
    'have.attr',
    'placeholder',
    'Digite seu e-mail'
)

Utilizar múltiplas asserções pode deixar o teste mais completo, mas é importante evitar validações desnecessárias.

12. Existência do atributo x valor do atributo

Existe uma diferença importante entre verificar apenas a existência de um atributo e verificar também o seu valor.

Para verificar apenas a existência: 

cy.get('#email')
.should('have.attr', 'type')

Para verificar o valor: 

cy.get('#email')
.should('have.attr', 'type', 'email')
🔎

Existência

Verifica se o atributo está presente no elemento.

🎯

Valor

Verifica se o atributo possui o valor esperado.

13. Atributos e propriedades

É importante diferenciar atributos HTML de propriedades dos elementos.

Por exemplo, um checkbox pode possuir o atributo checked: 

<input
type="checkbox"
checked

>

Para validar o estado atual do elemento, podemos utilizar asserções específicas: 

cy.get('input[type="checkbox"]')
.should('be.checked')
Importante:

Nem sempre validar diretamente um atributo é a melhor forma de verificar o estado atual de um elemento. Para estados como checked, disabled ou selected, o Cypress possui asserções próprias.

14. Validando elementos desabilitados

Podemos validar se um elemento está desabilitado utilizando a asserção be.disabled. 

<button disabled>
Salvar

O teste: 

cy.get('button')
.should('be.disabled')

Para verificar o estado oposto: 

cy.get('button')
.should('not.be.disabled')

15. Validando checkbox selecionado

Para verificar se um checkbox está marcado, podemos utilizar be.checked. 

<input
type="checkbox"
id="termos"

>

Depois de marcar o checkbox: 

cy.get('#termos')
.check()
.should('be.checked')

Também podemos verificar se ele não está marcado: 

cy.get('#termos')
.should('not.be.checked')

16. Validando opções selecionadas

Em elementos select, podemos verificar qual opção está selecionada. 

<select id="estado">

<option value="rj">
    Rio de Janeiro
</option>

<option value="sp">
    São Paulo
</option>

Podemos selecionar uma opção e validar seu valor: 

cy.get('#estado')
.select('rj')
.should('have.value', 'rj')

Para formulários, combinar interação e validação ajuda a garantir que a aplicação respondeu corretamente à ação realizada.

17. Atributos também podem ser utilizados em seletores

Além de validar atributos, também podemos utilizá-los para localizar elementos.

Por exemplo: 

<button
data-testid="login-button"

>
Entrar

Podemos localizar o botão através do atributo: 

cy.get('[data-testid="login-button"]')

E depois realizar uma validação: 

cy.get('[data-testid="login-button"]')
.should('have.attr', 'data-testid', 'login-button')

18. Exemplo completo

Vamos combinar localização, interação e validação de atributos.

HTML: 

<form>

<input
    id="email"
    type="email"
    name="email"
    placeholder="Digite seu e-mail"
    class="form-control"
>

<button
    id="login"
    type="submit"
    class="btn btn-primary"
>
    Entrar
</button>

Teste: 

describe('Formulário de login', () => {

it('deve possuir os atributos esperados', () => {

    cy.get('#email')
        .should('have.attr', 'type', 'email')
        .and('have.attr', 'name', 'email')
        .and(
            'have.attr',
            'placeholder',
            'Digite seu e-mail'
        )
        .and('have.class', 'form-control')

    cy.get('#login')
        .should('have.attr', 'type', 'submit')
        .and('have.class', 'btn')
        .and('have.class', 'btn-primary')

})

})
O que estamos validando?

📧 O tipo do campo de e-mail.

🏷️ O atributo name.

💬 O placeholder.

🎨 As classes CSS.

🔘 O tipo do botão.

19. Quando validar atributos?

A validação de atributos pode ser útil em diferentes situações durante a automação.

🔗

Links

Verificar href, target e outros atributos relacionados à navegação.

📝

Formulários

Validar type, name, placeholder e value dos campos.

🏷️

Classes

Verificar classes utilizadas para representar estilos ou estados.

🧩

Data attributes

Validar atributos utilizados como identificadores ou metadados da aplicação.

Erros comuns

❌

Validar atributos desnecessários

Criar verificações para características que não possuem importância para o comportamento do teste.

❌

Confundir atributo com estado

Utilizar uma validação de atributo quando existe uma asserção específica para o estado do elemento.

❌

Depender de classes visuais

Utilizar classes puramente visuais como principal estratégia para localizar elementos.

❌

Testar tudo ao mesmo tempo

Criar testes excessivamente grandes, difíceis de entender e manter.

Boas práticas

🎯

Valide o que importa

Concentre as asserções em comportamentos relevantes para o teste.

🔎

Prefira seletores estáveis

Utilize identificadores apropriados para reduzir a fragilidade dos testes.

🧩

Use asserções específicas

Utilize be.checked, be.disabled, have.value e outras asserções quando forem apropriadas.

🧹

Evite excesso de validações

Um teste deve ser claro e possuir um objetivo bem definido.
