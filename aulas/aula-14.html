cy.get()

Aprenda a localizar elementos da página utilizando o comando cy.get() e seletores CSS nos testes com Cypress.

Agora precisamos aprender como encontrar os elementos dessas páginas para poder interagir com eles e validar seus comportamentos.

O que é o cy.get()?

O cy.get() é um comando utilizado para localizar elementos da página utilizando seletores CSS.

Por exemplo, imagine o seguinte HTML: 

<button id="login">
Entrar

Podemos localizar esse botão utilizando seu ID: 

cy.get('#login')

🔎 cy.get() → procura elementos na página.

🎯 Seletor → informa qual elemento queremos localizar.

🧪 Resultado → o Cypress retorna o elemento encontrado para que outros comandos possam ser utilizados.

1. Sintaxe básica

A sintaxe básica do comando é: 

cy.get('seletor')

Por exemplo: 

cy.get('button')

Nesse caso, o Cypress procurará elementos button na página.

Também podemos utilizar: 

cy.get('input')
cy.get('h1')
cy.get('form')
🏷️

Tag

Podemos localizar elementos utilizando suas tags HTML.

🆔

ID

Podemos utilizar o identificador único do elemento.

🎨

Classe

Podemos localizar elementos através de classes CSS.

2. Localizando elementos por tag

Uma das formas mais simples de utilizar o cy.get() é através da tag HTML.

Imagine o seguinte elemento: 

<h1>
Página de Login

Podemos localizá-lo com: 

cy.get('h1')

Outro exemplo: 

<input type="text">
cy.get('input')
Atenção:

Seletores baseados apenas em tags podem localizar vários elementos. Por isso, em aplicações maiores, normalmente precisamos de seletores mais específicos.

3. Localizando elementos por ID

Podemos utilizar o atributo id para localizar um elemento.

HTML: 

<button id="login">
Entrar

Cypress: 

cy.get('#login')

O símbolo # representa um ID em um seletor CSS.

HTML: id="login"

Seletor: #login

4. Localizando elementos por classe

Também podemos utilizar classes CSS.

HTML: 

<button class="btn-login">
Entrar

Cypress: 

cy.get('.btn-login')

O ponto . representa uma classe em um seletor CSS.

HTML: class="btn-login"

Seletor: .btn-login

5. Localizando elementos por atributos

O CSS também permite localizar elementos através de atributos.

Por exemplo: 

<input type="email">

Podemos utilizar: 

cy.get('input[type="email"]')

Outro exemplo: 

<button data-testid="login-button">
Entrar

O elemento pode ser localizado através do atributo: 

cy.get('[data-testid="login-button"]')
Boa prática:

Atributos criados especificamente para automação, como data-testid ou data-cy, podem ajudar a criar seletores mais estáveis.

6. Combinando seletores

Podemos combinar diferentes partes de um seletor CSS.

HTML: 

<button id="login" class="btn-primary">
Entrar

Podemos utilizar: 

cy.get('#login')

Ou: 

cy.get('.btn-primary')

Também podemos combinar: 

cy.get('button#login')

Ou: 

cy.get('button.btn-primary')
Atenção:

Quanto mais específico for o seletor, menor tende a ser a quantidade de elementos correspondentes. Porém, especificidade excessiva também pode tornar o teste mais frágil.

7. Utilizando cy.get() com click()

Depois de localizar um elemento, podemos utilizar outros comandos do Cypress para interagir com ele.

Por exemplo: 

cy.get('#login')
.click()

O Cypress primeiro localiza o elemento e depois executa o clique.

🔎 cy.get() → encontra o botão.

🖱️ click() → realiza a interação.

8. Utilizando cy.get() com type()

O mesmo conceito pode ser utilizado para preencher campos de formulário.

HTML: 

<input id="email" type="email">

Teste: 

cy.get('#email')
.type('usuario@email.com')

O fluxo é:

🔎

Localizar

O cy.get() encontra o campo.

⌨️

Interagir

O type() insere o texto no campo.

9. Utilizando cy.get() com should()

O cy.get() também é utilizado frequentemente em conjunto com assertions.

Por exemplo: 

cy.get('h1')
.should('be.visible')

Nesse caso, o Cypress localiza o elemento h1 e verifica se ele está visível.

Podemos também validar seu conteúdo: 

cy.get('h1')
.should('contain', 'Login')

🔎 cy.get() → localiza.

✅ should() → valida.

10. Quando existem vários elementos

Um seletor pode corresponder a mais de um elemento.

Imagine: 

<button class="produto">
Produto 1

O comando: 

cy.get('.produto')

encontrará os elementos correspondentes ao seletor.

Importante:

Saber quantos elementos um seletor pode retornar é importante para evitar testes ambíguos.

11. Selecionando elementos específicos

Quando um seletor retorna vários elementos, podemos utilizar comandos para trabalhar com elementos específicos.

Primeiro elemento: 

cy.get('.produto')
.first()

Último elemento: 

cy.get('.produto')
.last()

Elemento de uma posição específica: 

cy.get('.produto')
.eq(1)

.first() → primeiro elemento.

.last() → último elemento.

.eq() → elemento de determinada posição.

12. Localizando elementos dentro de outro elemento

Podemos utilizar um seletor para localizar um elemento dentro de outro.

Imagine: 

<div class="login">

<input id="email">

<input id="senha">

Podemos localizar diretamente: 

cy.get('.login #email')

O seletor indica que queremos o elemento #email dentro de um elemento com a classe .login.

Conceito importante:

Seletores CSS permitem representar relações entre elementos da página.

13. Exemplo completo com formulário

Podemos combinar diferentes comandos para testar um formulário de login.

Imagine: 

<input
id="email"
type="email"

>

O teste poderia ser: 

describe('Login', () => {

it('deve preencher o formulário', () => {

    cy.visit('/login')

    cy.get('#email')
        .type('usuario@email.com')

    cy.get('#password')
        .type('123456')

    cy.get('#login')
        .click()

})

})

🌐 cy.visit() → acessa a página.

🔎 cy.get() → localiza os campos.

⌨️ type() → preenche os campos.

🖱️ click() → envia o formulário.

14. Utilizando data-cy

Uma estratégia comum para automação é adicionar atributos específicos aos elementos da aplicação.

Por exemplo: 

<button data-cy="login-button">
Entrar

Podemos localizar o elemento utilizando: 

cy.get('[data-cy="login-button"]')

Essa abordagem será estudada com mais detalhes na próxima aula, quando veremos estratégias de seleção de elementos.

Boa prática:

Atributos dedicados à automação podem reduzir a dependência de classes visuais ou da estrutura interna do HTML.

Erros comuns ao utilizar cy.get()

❌

Seletor incorreto

Utilizar um seletor que não corresponde a nenhum elemento da página.

❌

Classe instável

Depender de classes utilizadas apenas para estilização visual.

❌

Seletor genérico demais

Utilizar seletores como button ou input quando existem muitos elementos semelhantes.

❌

Ignorar múltiplos elementos

Não considerar que um seletor pode retornar vários elementos.

Boas práticas com cy.get()

🎯

Utilize seletores estáveis

Prefira seletores que não dependam de detalhes visuais que mudam frequentemente.

🧩

Seja específico

Utilize seletores que identifiquem claramente o elemento desejado.

🧪

Combine com assertions

Depois de localizar o elemento, valide seu estado ou comportamento quando necessário.

🔐

Prefira atributos de teste

Quando disponíveis, atributos dedicados à automação podem facilitar a manutenção.

Fluxo básico de automação

🌐 1. cy.visit() → acessa a página.

🔎 2. cy.get() → localiza o elemento.

🖱️ 3. click() → interage com o elemento.

⌨️ 4. type() → preenche informações.

✅ 5. should() → valida o resultado.

Esse fluxo aparecerá frequentemente nos testes que construiremos nas próximas aulas.
