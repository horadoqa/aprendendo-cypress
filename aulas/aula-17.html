O que é o type()?

O type() é um comando utilizado pelo Cypress para inserir texto em elementos que aceitam entrada de dados.

Ele é muito utilizado para preencher campos de formulários, como nome, e-mail, senha, endereço e outros dados. 

cy.get('input')
.type('Olá Cypress!')

Nesse exemplo, o Cypress localiza um elemento input e digita o texto informado.

⌨️ cy.get() → localiza o campo.

✍️ type() → insere o texto.

1. Sintaxe do type()

A estrutura básica do comando é: 

cy.get('seletor')
.type('texto')

Por exemplo: 

cy.get('#nome')
.type('Maria')

Nesse caso, o Cypress irá localizar o elemento com o atributo id="nome" e inserir o texto Maria.

🔎

Seletor

Define qual elemento receberá a informação.

⌨️

Texto

Define o conteúdo que será digitado.

2. Preenchendo um input

Um dos usos mais comuns do type() é preencher elementos input.

Considere o seguinte HTML: 

<input
type="text"
id="nome"

>

Podemos preencher esse campo utilizando: 

cy.get('#nome')
.type('João da Silva')

O resultado será equivalente à ação de um usuário digitando o nome no campo.

Importante:

O elemento precisa estar disponível e aceitar entrada de texto para que o comando type() consiga executar a ação.

3. Preenchendo um campo de e-mail

O type() também pode ser utilizado para preencher campos de e-mail.

Exemplo: 

<input
type="email"
id="email"

>

Teste: 

cy.get('#email')
.type('usuario@email.com')

Podemos combinar o preenchimento com uma validação: 

cy.get('#email')
.type('usuario@email.com')
.should('have.value', 'usuario@email.com')

📝 type() → preenche o campo.

✅ should() → verifica o valor preenchido.

4. Preenchendo um campo de senha

Campos do tipo password também podem ser preenchidos utilizando type(). 

<input
type="password"
id="senha"

>

No teste: 

cy.get('#senha')
.type('Senha@123')

Um fluxo de login poderia ser: 

cy.get('#email')
.type('usuario@email.com')

cy.get('#senha')
.type('Senha@123')
Atenção:

Evite armazenar senhas reais diretamente no código dos testes. Em projetos reais, utilize estratégias apropriadas para gerenciamento de credenciais.

5. Preenchendo um formulário

Podemos utilizar vários comandos type() para preencher diferentes campos de um formulário.

Imagine o seguinte formulário: 

<input id="nome">

O teste poderia ser: 

cy.get('#nome')
.type('Maria Silva')

cy.get('#email')
.type('maria@email.com')

cy.get('#telefone')
.type('21999999999')
👤

Nome

Campo preenchido com o nome do usuário.

📧

E-mail

Campo preenchido com um endereço de e-mail.

📱

Telefone

Campo preenchido com um número de telefone.

6. Combinando type() com click()

Em um fluxo real, frequentemente precisamos preencher campos e depois clicar em um botão.

Por exemplo: 

cy.get('#email')
.type('usuario@email.com')

cy.get('#senha')
.type('Senha@123')

cy.get('#entrar')
.click()

Esse fluxo representa uma ação comum em uma tela de login.

🔎 Localizar → ⌨️ Preencher → 🖱️ Clicar → ✅ Validar

7. Limpando um campo antes de digitar

Em algumas situações, o campo pode possuir um valor previamente preenchido.

Podemos utilizar a opção { force: true } em situações específicas, mas para limpar o conteúdo de um campo existe uma abordagem mais apropriada: 

cy.get('#nome')
.clear()
.type('Novo Nome')

O comando clear() remove o conteúdo atual do campo antes de inserir o novo valor.

Boa prática:

Utilize clear() quando o objetivo do teste for substituir explicitamente um valor já existente. Não é necessário limpar um campo que já está vazio.

8. clear() e type() juntos

Uma combinação bastante comum é: 

cy.get('#email')
.clear()
.type('novo@email.com')

Nesse exemplo:

🧹 clear() → remove o valor existente.

⌨️ type() → insere o novo valor.

9. Utilizando opções no type()

O comando type() aceita opções que permitem controlar alguns aspectos da interação.

Uma dessas opções é o delay. 

cy.get('#nome')
.type('Maria', {
    delay: 100
})

Nesse caso, o Cypress adiciona um intervalo entre as teclas digitadas.

Quando utilizar?

Essa opção pode ser útil quando estamos testando comportamentos específicos relacionados à digitação, como componentes que respondem enquanto o usuário digita.

10. A opção force

O Cypress realiza verificações antes de interagir com um elemento.

Em situações específicas, podemos encontrar um elemento que está presente no DOM, mas não está disponível para uma interação normal.

O comando aceita a opção: 

cy.get('#campo')
.type('texto', {
    force: true
})
Atenção:

O uso de force: true deve ser consciente. Ele pode fazer o Cypress interagir com um elemento mesmo quando as verificações normais de interação não seriam satisfeitas.

Antes de utilizá-lo, investigue por que o elemento não está disponível para interação.

11. Caracteres especiais

O type() também permite utilizar sequências especiais para simular determinadas teclas do teclado.

Por exemplo: 

cy.get('#campo')
.type('Texto{enter}')

Nesse exemplo, o Cypress digita o texto e depois simula a tecla Enter.

Outro exemplo: 

cy.get('#campo')
.type('Texto{backspace}')

A utilização de teclas especiais pode ser útil em componentes que dependem de eventos do teclado.

Exemplo:

Um campo de busca pode executar a pesquisa quando o usuário pressiona Enter. 

cy.get('#busca')
.type('Cypress{enter}')

12. Validando o valor digitado

Depois de utilizar type(), podemos verificar se o valor esperado foi inserido no campo. 

cy.get('#nome')
.type('Maria')
.should('have.value', 'Maria')

Nesse exemplo, o teste verifica se o campo possui exatamente o valor informado.

⌨️

type()

Insere o valor no campo.

✅

should()

Verifica se o valor esperado está presente.

13. Exemplo completo

Vamos combinar os conceitos aprendidos em um pequeno teste de formulário. 

describe('Cadastro de usuário', () => {

it('deve preencher o formulário', () => {

    cy.visit('/cadastro')

    cy.get('#nome')
        .type('Maria Silva')

    cy.get('#email')
        .type('maria@email.com')

    cy.get('#senha')
        .type('Senha@123')

    cy.get('#nome')
        .should('have.value', 'Maria Silva')

    cy.get('#email')
        .should('have.value', 'maria@email.com')

})

})

O teste navega até a página, preenche os campos e verifica os valores inseridos.

🌐 cy.visit() → acessa a página.

🔎 cy.get() → localiza o campo.

⌨️ type() → preenche o campo.

✅ should() → valida o resultado.

14. type() em diferentes tipos de campos

O type() pode ser utilizado em diversos elementos que aceitam entrada de texto.

Elemento Exemplo Uso
input text type() Campos de texto.
input email type() Endereços de e-mail.
input password type() Senhas e credenciais.
textarea type() Textos maiores e comentários.

15. Preenchendo um textarea

O type() também pode ser utilizado para preencher elementos textarea.

HTML: 

<textarea id="mensagem"></textarea>

Teste: 

cy.get('#mensagem')
.type('Esta é uma mensagem de teste.')

Também podemos validar o conteúdo: 

cy.get('#mensagem')
.should(
    'have.value',
    'Esta é uma mensagem de teste.'
)

Erros comuns ao utilizar type()

❌

Seletor incorreto

O teste não encontra o campo porque o seletor utilizado não corresponde ao elemento esperado.

❌

Elemento não permite entrada

O comando é utilizado em um elemento que não aceita entrada de texto.

❌

Usar force sem investigar

Utilizar force: true para esconder um problema de sincronização ou de implementação.

❌

Não validar o resultado

Preencher o campo sem verificar se o valor esperado realmente foi inserido.

Boas práticas com type()

🎯

Utilize bons seletores

Prefira seletores estáveis e específicos para localizar os campos.

🧪

Valide os valores

Utilize assertions quando fizer sentido verificar o conteúdo preenchido.

🧹

Use clear() quando necessário

Limpe o campo explicitamente quando o teste precisar substituir um valor existente.

⚠️

Evite force sem necessidade

Investigue problemas de visibilidade, estado e sincronização antes de usar force.

Fluxo de automação com type()

Um fluxo comum de automação pode seguir esta sequência:

1️⃣ Visitar a página → cy.visit()

2️⃣ Localizar o campo → cy.get()

3️⃣ Preencher o campo → type()

4️⃣ Interagir com outros elementos → click()

5️⃣ Validar o resultado → should()

Esses comandos podem ser combinados para representar fluxos completos da aplicação.

Exemplo: teste de login

Vamos utilizar os comandos estudados para criar um exemplo de login. 

describe('Login', () => {

it('deve realizar login com sucesso', () => {

    cy.visit('/login')

    cy.get('[data-testid="email"]')
        .type('usuario@email.com')

    cy.get('[data-testid="senha"]')
        .type('Senha@123')

    cy.get('[data-testid="entrar"]')
        .click()

})

})
Observe:

O type() é responsável pela entrada dos dados, enquanto o click() realiza a ação de envio do formulário.
